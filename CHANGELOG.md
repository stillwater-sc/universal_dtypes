# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

Release sections below the marker are generated by python-semantic-release from
conventional commits; the `Unreleased` section above it is maintained by hand.

Versioning: stable `2.x`, following conventional semver — `feat` bumps the
**minor** component, `fix`/`perf`/`refactor` bump the **patch**, and a
`feat!`/`BREAKING CHANGE` footer bumps the **major** (managed by
python-semantic-release). The first stable major was `2.0.0`, cut manually; it
skips the yanked `1.0.0` (see [`docs/RELEASING.md`](docs/RELEASING.md) §3).

## v2.0.0 (2026-08-09)

**First stable release.** The public API is now committed to Semantic Versioning
guarantees. This release is **functionally identical to `0.23.0`** — it marks the
surface as stable rather than adding features. It intentionally **skips `1.0.0`**,
which was published in error very early and yanked; PyPI permanently reserves a
version number, so the first stable major is `2.0.0` (see
[`docs/RELEASING.md`](docs/RELEASING.md) §3).

### Stable surface

- **Dtypes** — NumPy 2.x custom dtypes for the Universal number systems:
  `bfloat16`; the posit family (`posit8/16/32/64` plus es-variants and
  non-power-of-two widths); `cfloat` (`fp16`, `fp8e5m2`); `lns` (`lns16/32`);
  `fixpnt`, including the TI/ADI DSP formats (`q7/q15/q31/iq24/q5_23`); and the
  `dd`/`td`/`qd` high-precision cascades.
- **Operations** — element-wise arithmetic and the math ufuncs (incl. `**`,
  `minimum`/`maximum`, `clip`), comparisons, sort/argsort, and reductions under a
  pinned in-type accumulation contract.
- **Casts** — value-domain casts between any two universal dtypes
  (cascade-mediated so wide types keep full precision), plus
  `float16`/`float32`/`float64`/int/bool.
- **Python integration** — hashable scalars, pickling, string-name resolution,
  and an optional pandas `ExtensionDtype`/`ExtensionArray` via the `[pandas]`
  extra.

The complete per-feature history is in the `0.x` sections below.
