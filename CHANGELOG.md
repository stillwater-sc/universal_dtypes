# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

Release sections below the marker are generated by python-semantic-release from
conventional commits; the `Unreleased` section above it is maintained by hand.

Versioning: pre-1.0 while the dtype implementation is built out, following
conventional semver — `feat` bumps the **minor** component, `fix`/`perf`/
`refactor` bump the **patch** component (managed by python-semantic-release).

## [Unreleased]

### Added

- **`fixpnt16` / `fixpnt8` NumPy dtypes (issue #29)** — Universal's saturating
  fixed-point (Q8.8 / Q4.4) via the harness: uniform absolute resolution, exact
  addition within range, saturation on overflow, and no NaN/Inf. Fills the
  README-spec gap and joins a new `fixpnt_dtypes` registry. Enables the DSP
  application study to come.
